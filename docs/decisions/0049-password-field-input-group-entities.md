
## Обновление (2026-10-07): форма входа — виджет, экран — серверный

Разметка формы жила прямо в `pages/login/ui/LoginScreen.tsx`: экран сам
импортировал `Controller`, `useSignIn` и семь компонентов `shared/ui`.
Владелец заметил, что по FSD это виджет, — и это ровно тот приём, который
в проекте уже есть: `widgets/waitlist-form` рендерит форму,
`features/join-waitlist` держит схему и хук.

Форма переехала в `widgets/sign-in-form/ui/SignInForm.tsx`. В
`features/sign-in` ничего не изменилось: схема, Server Action, редирект и
тост — там же. Экран остался тонким: знак, заголовок, подзаголовок и
`<SignInForm />`.

Побочное следствие — экран перестал быть клиентским. Единственное, что
требовало `"use client"`, это `useSignIn`; без него `LoginScreen` стал
серверным компонентом с `getTranslations`, как `ComingSoonScreen`, а
клиентский остров на странице теперь один — сама форма.
