# AGENTS.md

Вход для AI-агентов, работающих в этом репозитории. Содержания здесь
нет намеренно: один источник правды — [`CLAUDE.md`](./CLAUDE.md), и
второй файл с теми же правилами разошёлся бы с ним на первой же правке.

**Прочитать до первой строчки кода:**

1. [`CLAUDE.md`](./CLAUDE.md) — структура репозитория, правила
   Feature-Sliced Design, дизайн-система, модель доступа, договорённости,
   команды. Всё остальное — следствие.
2. [`docs/decisions/`](./docs/decisions) — ADR, по одному на решение, с
   вариантами и причиной выбора.

**Четыре правила, которые нарушают чаще всего:**

- **Решение фиксируется в ADR**, а не в переписке: `docs/decisions/
  NNNN-краткое-описание.md`, по-русски, контекст → варианты → решение →
  последствия.
- **Язык:** интерфейс, код и комментарии — британский английский
  (`organise`, `colour`); ADR, `CLAUDE.md`, `CHANGELOG.md` и этот файл —
  по-русски.
- **Переменные окружения** — только через `envs/*.local.env` и
  `shared/config/env.ts`. Реальные значения не коммитятся.
  `DEV_MODE=true` в Production запрещён.
- **Схема базы** меняется только файлом миграции в
  `backend/supabase/migrations/`. `supabase db reset --linked` уничтожает
  данные в облаке — только локально, без `--linked`.

**Перед тем как писать свой компонент:** сначала `web/src/shared/ui`,
потом реестр shadcn (`npx shadcn@latest search @shadcn -c web -q "<имя>"`),
и только потом свой — с обоснованием в ADR.

**Проверки:** `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm db:test`.
Когда их гоняет CI — ADR 0052.

`web/AGENTS.md` и `web/CLAUDE.md` — не этот файл: их генерирует `next dev`
(см. блок `nextjs-agent-rules` внутри), и вручную правится только то, что
лежит вне маркеров.
